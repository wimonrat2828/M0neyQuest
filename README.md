## 🎯 ภาพรวมโครงงาน (Project Overview)

**MoneyQuest** คือเว็บแอปพลิเคชันที่นำแนวคิด Gamification (Quest & Pet System) เข้ามาผสานกับการบริหารจัดการการเงินส่วนบุคคล เพื่อช่วยเปลี่ยนการบันทึกรายรับ-รายจ่ายที่น่าเบื่อให้กลายเป็นการผจญภัยที่สนุกและสร้างวินัยทางการเงินได้อย่างยั่งยืน

### ฟังก์ชันการทำงานแต่ละหน้า
* **Page 1: Dashboard (`/page1`)**
  * สรุปยอดรวมรายรับ รายจ่าย และยอดเงินคงเหลือสุทธิ
  * วิเคราะห์สัดส่วนรายรับ-รายจ่ายตามหมวดหมู่
  * ระบบสัตว์เลี้ยงการเงิน (MoneyPet) ที่เลเวลและสถานะจะเติบโตขึ้นตามเงินออมสะสม
* **Page 2: Income & Expense (`/page2`)**
  * ฟอร์มบันทึกรายการรายรับ-รายจ่าย
  * เลือกหมวดหมู่ (อาหาร, เดินทาง, ช้อปปิ้ง, เงินเดือน, ฯลฯ) จำนวนเงิน และวันที่
  * ตารางแสดงรายการธุรกรรมล่าสุด
* **Page 3: Quest Planner (`/page3`)**
  * วางแผนตั้งเป้าหมายการออมเงิน (เช่น ซื้อแล็ปท็อป, เงินสำรองฉุกเฉิน)
  * คำนวณเปอร์เซ็นต์ความคืบหน้า และยอดเงินที่ต้องออมต่อเดือนโดยอัตโนมัติ
* **Page 4 (Bonus Page): Daily Quest (`/page4`)**
  * ระบบสุ่มภารกิจออมเงินประจำวัน (เช่น งดชานมไข่มุก, ทำอาหารกินเอง)
  * สามารถกดทำภารกิจเพื่อบันทึกยอดเงินออมเข้าสู่ระบบได้ทันที
* **Object-Oriented Programming (`models.py`)**
  * คลาส `Goal`: สำหรับคำนวณความคืบหน้าของเป้าหมาย, ยอดเงินคงเหลือที่ต้องเก็บ และเป้าหมายรายเดือน
  * คลาส `Pet`: คำนวณเลเวล และสถานะความสุขของสัตว์เลี้ยงตามวินัยการออม

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (How to Run)

### สำหรับระบบปฏิบัติการ Windows
1. **ติดตั้งสภาพแวดล้อม (รันครั้งแรก):**
   ```cmd
   setup.bat
   ```
2. **รันเว็บแอปพลิเคชัน:**
   ```cmd
   run.bat
   ```
   เปิดเว็บเบราว์เซอร์ไปที่: [http://localhost:5000](http://localhost:5000)
3. **ตรวจสอบความถูกต้องและคะแนน:**
   ```cmd
   check.bat
   ```

### สำหรับระบบปฏิบัติการ macOS / Linux
1. **ติดตั้งสภาพแวดล้อม:**
   ```bash
   bash setup.sh
   ```
2. **รันเว็บแอปพลิเคชัน:**
   ```bash
   bash run.sh
   ```
   เปิดเว็บเบราว์เซอร์ไปที่: [http://localhost:5000](http://localhost:5000)
3. **ตรวจสอบความถูกต้องและคะแนน:**
   ```bash
   bash check.sh
   ```

  - Python foundations (if/else, loop, def, class): 30 / 30

- **`pytest`:** Passed ทั้ง 4 การทดสอบ (100%)
